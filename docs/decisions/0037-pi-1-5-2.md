# 0037. Pi 1.5.2

## Status

Accepted, 2026-11-10. Follows [0035](0035-pi-1-5-0.md), whose decisions stand.

## Context

Pi released 1.5.1 and 1.5.2 a week after the pins moved to 1.5.0. For this host, 1.5.1 matters most:

- pi-durable fixes a task that stayed `waiting` (or `completing`, with idle waits never resolving) when the last task
  it waited for ended while a scheduler pass was planning: a generation waiting on parallel tool calls could hang.
- `SqliteStorage.commit()` takes a few SQL statements per call instead of about eight per batch.
- Chord's root now exports Chord v2. The foundations this host uses moved to subpaths: `Context` to
  `@earendil-works/chord/context`, `Draft` to `/delta`, `JsonValue`, `JsonRepresentation` and `copyJson` to `/json`,
  the watch types to `/watch`.
- pi-schema's `number` and `integer` no longer accept `NaN` or an infinity, so a tool argument cannot be one.

1.5.2 changes nothing in the packages this host calls (pi-coding-agent's session fork is Pi's own CLI).

## Decision

- Pin every Pi package at 1.5.2. The `overrides` of ADR 0035 stay as they are: Chord still asks for `ws` 8.21.0, and
  pi-coding-agent still pins `minimatch` 11.0.3.
- Import Chord's foundations from their subpaths. Nothing else in the host's code changes.
- The pinned release is one constant, `SDK` (`src/runtime/sdk.ts`), which `--help`, `--version` and the unknown-model
  error name. A test holds it to `package.json` and to the installed pi-durable, so a later move of the pins cannot
  leave one of them behind.
- Per-conversation compaction settings (`configure({ compaction })`, new in 1.5.1) are not used. Pi's compactions are
  still declined by the `uniichat` extension (ADR 0015): agents copy Pi's stored agent, so a setting on Pi would
  reach them, and a chat that stores the field could no longer be opened as written by a 1.5.0 checkout.

## Consequences

- No migration: the Durable SQLite schema is still version 2 and the built-in documents keep their versions, so a
  1.5.0 checkout opens a chat that 1.5.2 wrote, and rolling back needs no backup restore.
- The model catalog is pi-ai 1.5.2's. Among its additions is `anthropic/claude-fable-5-2`; `claude-cli/fable` still
  follows the `claude` CLI's own alias.
